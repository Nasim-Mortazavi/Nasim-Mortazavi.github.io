About

Bridging neuroscience,
statistics, and clinical data

I am a Ph.D. Candidate in Neuroscience at Western University (Schulich School of Medicine & Dentistry), working on human intracranial electrophysiology recordings collected from patients with temporal lobe epilepsy. My thesis investigates how the hippocampus — particularly CA1 — supports associative learning and memory, using stereo-EEG (SEEG) local field potentials and single-unit activity.

Before neuroscience, I trained as a physicist: I hold an M.Sc. in Computational Physics from Western University and an M.Sc. in Theoretical Particle Physics from Isfahan University of Technology. That quantitative foundation shapes how I approach every analysis — with emphasis on model validity, reproducibility, and honest uncertainty quantification.

Across both academic and industry contexts, I build end-to-end analytical pipelines — from raw clinical data and QC through statistical modelling (GLMM, Bayesian inference) and ML-based detection — and communicate results to clinicians, engineers, and scientific teams. I am fluent in English and a native Farsi speaker; Canadian Permanent Resident, available without sponsorship.

Research

Core Research Areas

My work combines human neurophysiology, statistical modelling, and open toolbox development to study memory and learning in the human brain.

🌊

Hippocampal Memory Dynamics

Characterising how hippocampal CA1 sharp-wave ripples, theta oscillations, and ensemble activity support associative encoding and subsequent recall during virtual navigation tasks in SEEG-implanted patients.

SEEG / iEEG Sharp-Wave Ripples CA1 Associative Memory
⚡

Interictal Discharge Detection & Impact

Developing discriminative algorithms to separate physiological ripples from pathological interictal epileptiform discharges (IEDs), and quantifying how IED burden disrupts hippocampal encoding signals and downstream memory performance.

IED Detection SWR Classification PyTorch CNN Epilepsy
📐

Statistical Modelling of Neural Events

Applying generalized linear mixed-effects models (GLMM), Bayesian inference, and state-space models to link trial-level neural features to behaviour — accounting for subject variability, electrode nesting, and learning-state trajectories.

GLMM / lme4 Bayesian Inference State-Space Models R & Python
🔬

Human Single-Neuron Recording Programmes

Building the clinical infrastructure, vendor relationships, and spike-sorting pipelines required to capture single-unit activity from hybrid macro/micro-electrodes in a hospital epilepsy monitoring unit — among Canada's first such programmes.

Single-Unit Recording Spike Sorting Clinical Infrastructure Blackrock / DIXI

Projects

Selected Research Projects

End-to-end research contributions — from clinical data collection and signal processing through statistical modelling and open toolbox development.

🌊

SEEG Associative Memory Modelling — CA1 Focus

End-to-end Python/R pipelines linking trial-level SEEG features (sharp-wave ripple rate, spectral power, PAC) to associative memory performance across 25 patients. GLMM models account for electrode nesting, subject variability, and IED co-occurrence. Two manuscripts under revision.

Python R / lme4 GLMM SEEG
🛠️

TODs — Transient Oscillation Detectors Toolbox

Open-source toolbox (Python/MATLAB) for detecting and characterising transient oscillatory events — sharp-wave ripples, spindles, high-gamma bursts — in noisy human intracranial recordings. Includes 1D CNN classifier (PyTorch), QC framework, and BIDS-compatible outputs. Under revision for publication.

PyTorch Python BIDS Open Source
⚡

SWR vs. IED Discrimination in Epilepsy

Discriminative feature pipeline to separate physiological sharp-wave ripples from pathological interictal discharges in hippocampal SEEG channels. Spectral shape, event duration, and coupling context features benchmarked across patients; imbalance-aware evaluation with threshold optimisation.

scikit-learn PyTorch Signal Processing Epilepsy
🗺️

3D Electrode Localisation — HippUnfold Integration

Python workflow combining HippUnfold subfield segmentation, post-implant CT/MRI coregistration, and 3D Slicer scripting to assign SEEG contacts to hippocampal subfields (CA1/CA3/DG) with automated visual QC. Integrated into downstream statistical modelling pipelines.

Python HippUnfold 3D Slicer Neuroimaging
📈

State-Space Learning Curve Estimation

Adapted the Smith et al. (2004) state-space framework to recover trial-wise learning probability from binary behavioural sequences in the associative memory task. Trial-level learning state used as a covariate in GLMM models. Porting MATLAB toolbox to Python for open-source release.

Python State-Space Behavioural Modelling In Progress
🐒

Decoding Working Memory from Primate Multi-Array Recordings

Random-forest decoders trained on multi-electrode array spiking data from non-human primate prefrontal cortex to predict remembered target location in 3D space, working-memory load, and item identity. Established population-code baselines informing later human analyses.

Python scikit-learn Random Forests Systems Neuro
